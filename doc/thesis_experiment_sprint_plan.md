## 5. 风险预案

### STK 卡住

- [ ] 使用 STK-like 手工场景兜底。
- [ ] 论文中先写“基于可见窗口数据的场景仿真”。
- [ ] 后续再替换真实 STK 数据。

### CDP 卡住

- [ ] 模式选择先不强依赖 CDP。
- [ ] CDP 只作为理论候选。
- [ ] CDP 实物实验放到后续补充。
- [ ] 整理 CDP 新论文模型：RS 分发，多颗工作卫星并行计算，结果直接回传 GS。
- [ ] 清理 CDP 旧聚合卫星表述：不再默认使用 `parallel_aggregator = SAT-xx`。
- [ ] 重命名 CDP 理论链路字段：`b_dist` 表示 RS 到工作卫星，`b_return` 表示工作卫星到 GS。
- [ ] 修正 CDP 理论代码中的 Mbps / MB/s 单位一致性。
- [ ] 后续再决定是否接入 CDP 实物实验和模式选择主流程。

### 实物实验卡住

- [ ] 只做一组最小实验。
- [ ] 用实物结果证明理论趋势。
- [ ] 其余实验用理论仿真补足。

### 能耗测不准

- [ ] 只做理论能耗。
- [ ] 不做真实能耗。
- [ ] 实物实验只验证时延和内存趋势。
