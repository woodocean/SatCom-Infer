# STK 动态拓扑下跨模型可行率与完成率汇总

实验入口：`mode_selection_experiment.py`

统一设置：
- STK 动态时间片：每个模型 42 个有效 slot。
- Batch size：64。
- 候选模式：`PMP / GS-Only / Sat-Only / CDP / FWMS-Feature / Oracle-Min-Latency`。
- `FWMS-Feature`：论文式特征加权模式边界判别。
- `Oracle-Min-Latency`：所有可行模式中预测时延最小的上界基线。

## 直接结论

- 当 CDP 可行时，当前理论模型下 `Oracle-Min-Latency` 全部选择 CDP，说明数据并行模式在低时延上界上优势非常明显。
- VGG19 和 ViT-Huge 的 CDP/Sat-Only 可行率为 0%，说明完整模型上星执行存在明确内存边界，固定使用 CDP 会直接失效。
- `FWMS-Feature` 的价值不应表述为“总能选到最低时延模式”，而应表述为“基于可行性和任务特征的模式边界判别与保底机制”。
- 当前 `FWMS-Feature` 采用等权特征，结果偏向 PMP；如果后续要让它更贴近低时延 Oracle，需要校准特征权重或把 Oracle 明确作为对照上界而非 FWMS 本体。
