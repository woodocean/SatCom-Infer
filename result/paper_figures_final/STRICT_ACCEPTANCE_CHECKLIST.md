# STRICT_ACCEPTANCE_CHECKLIST

这份清单故意站在最严格、最挑剔的验收老师视角发问。

如果这些问题你答不上来，说明图虽然画完了，但论证链还不够硬。

## 总体追问

1. 你的 6 个实验分别回答什么问题？如果删掉其中任意一个，论文论证链会缺哪一环？
2. 你为什么敢把 `PMP`、`CDP`、`GS-Only`、`Sat-Only` 放在一张图里比较？它们的可行域和代价结构根本不同，比较口径真的统一了吗？
3. 你的所有归一化基准为什么有时选 `GS-Only`，有时选 `Sat-Only`？这会不会让读者误以为图与图之间可直接横向比较？
4. 你的结论里哪些是“观察到的现象”，哪些是“机制解释”，哪些已经上升成“普遍规律”？请逐条区分。
5. 哪几张图只是说明“在当前参数下如此”，而不是说明“方法本质上如此”？

## 实验 1

1. 为什么只选 `slot_033_064500_065000`？是人工挑了一个有利于 `LADP` 的时间片吗？
2. 如果把最窄链路从 `116.95 Mbps` 换成 `300 Mbps` 或 `30 Mbps`，结论会不会变？
3. `GA` 的采样次数为什么是 `100`？有没有做过收敛性检查？
4. `ViT-Huge` 退化为 `GS-Only`，你怎么证明核心原因是“特征压缩不足”，而不是“卫星资源太弱”？
5. 这个实验能否支持“PMP 模式普遍有效”？如果不能，它最多支持到什么程度？

## 实验 2

1. 你说这是“节点数量敏感性”，但节点数变了以后，总可用资源也变了，这还是纯节点数量实验吗？
2. 为什么节点上限是 `5`？如果扫到 `8` 或 `10`，趋势是否可能反转？
3. `YOLOv5` 在异构场景下变差，你怎么解释？这是 `LADP` 失效，还是通信开销主导？
4. 实验2为什么不是动态多 slot 平均？如果不是，它和实验5/6的结论能直接拼起来吗？
5. 你有没有证明异构模板本身不是“人为构造出来刚好让某模型受益”的？

## 实验 3

1. 最终只展示 `ResNet101`，那 `YOLOv5 / VGG19` 为什么不展示？是因为趋势不稳定吗？
2. `LAWA` 和 `Greedy` 在小 batch 上差距不大，你凭什么说 `LAWA` 值得更复杂的分配过程？
3. 为什么归一化基准选 `Sat-Only`？如果改成 `GS-Only`，视觉结论会不会变化？
4. 这个实验没有真实动态拓扑，能否代表真实卫星网络中的 `CDP`？
5. 你能否明确指出：实验3证明的是“异构感知分配有效”，而不是“CDP 一定优于 PMP”？

## 实验 4

1. 最终只展示 `YOLOv5`，这是否属于选择性展示？
2. worker 数量增加时，为什么还能说是单变量实验？新增 worker 同时带来了新增算力、新增链路和新增回传路径。
3. 为什么去掉了 `Uniform / Random`？是为了让图更聚焦，还是因为它们会削弱你想讲的故事？
4. `LAWA` 的收益是不是只来自“挑中强 worker”，而不是算法本身更聪明？
5. 你能否证明 `worker=5` 不是这组异构参数下偶然的甜点，而是真正趋势延续？

## 实验 5

1. 为什么实验5最后变成 `YOLOv5 / ResNet101` 倾向 `CDP`，而不是之前你直觉以为的 `PMP`？你是被新 profile 改写结论了吗？
2. 为什么 `FWMS` 不等于每个模型当前图中的最小柱？如果不是最小，它到底优化什么？
3. 你所谓公平口径里，“PMP / GS-Only / Sat-Only 同路由”是为了公平，还是反而限制了某个模式的真实最优性能？
4. `CDP active_sat_count >= 3` 为什么合理？为什么不是 `2` 或 `4`？
5. `VGG19 / ViT-Huge` 的 `CDP` 和 `Sat-Only` 不可行，是算法不可行还是资源配置不可行？如果把内存从 `2 GB` 改成 `4 GB`，结论会不会完全改写？
6. 共同 slot 只有 `28` 个，剩下的 slot 为什么被剔除？被剔除的那些 slot 是否恰好对你的结论不利？

## 实验 6

2. `FWMS` 在 `batch=16` 没有直接等于 `CDP` 最优值，这说明它的阈值设计不够激进吗？
3. `batch=128` 时 `CDP` 和 `Sat-Only` 不可行，这个不可行到底由什么约束触发？内存、链路还是 worker 数？
4. 绝对时延图和归一化时延图能讲的是同一件事吗？如果不能，你答辩时应该先讲哪一张？
5. 你怎么证明 `GS-Only` 的近线性增长不是因为 profile 近似线性外推，而是真正物理可解释的结果？

## 老师最可能抓住不放的薄弱点

1. “你这几张图里，有多少是真实动态统计，有多少是受控仿真？”
2. “你说公平，公平到底体现在路由、时间片、算力、内存、还是可行域？”
3. “你是先看到结果，再调整口径把故事讲顺的吗？”
4. “为什么有些实验只保留一个模型？是因为其余模型结论不支持你的论点吗？”
5. “你所谓模式选择有效，究竟是比固定模式更快，还是只是比固定模式更稳？”

## 如果必须更稳，答辩时建议主动承认

1. 实验1是单 slot 机制验证，不是统计泛化实验。
2. 实验2是受控理论扫描，目的是解释机制，不是复现实网平均性能。
3. 实验3/4是 `CDP` 局部机制实验，重点是 `LAWA` 的分配价值。
4. 实验5/6才是多时间片公平模式比较，但仍然是 profile 驱动仿真，不是完整半实物闭环。
5. 因此论文当前最硬的结论应该写成“在当前配置和评测口径下”，而不是“普遍证明”。
